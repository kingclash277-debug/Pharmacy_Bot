# 🧪 اختبارات التحديثات الشاملة

## ✅ قائمة الاختبارات

### **الاختبار 1️⃣: التسجيل التلقائي (Auto-Save)**

#### الخطوات:
1. ابدأ محادثة جديدة مع البوت من حساب جديد
2. اكتب `/start`
3. افتح قاعدة البيانات وتحقق:

```sql
SELECT user_id, username, full_name, role FROM users ORDER BY user_id DESC LIMIT 1;
```

#### ✅ معايير النجاح:
- [ ] `user_id` مملوء (معرّف التليجرام)
- [ ] `username` مملوء (إما من التليجرام أو `user_XXXXX`)
- [ ] `full_name` مملوء (الاسم الأول + الأخير)
- [ ] `role` = `'patient'` (أو `'admin'` إن كان ADMIN_ID)

#### 🔍 اختبار متقدم:
```sql
-- تحقق من أن البيانات تتطابق مع ملف التليجرام
SELECT * FROM users WHERE user_id = 'YOUR_USER_ID';

-- يجب أن ترى:
-- user_id: معرّفك
-- username: اسم المستخدم من التليجرام
-- full_name: اسمك الكامل
-- role: patient
```

### **الاختبار 2️⃣: عرض سجل الجرعات (Intake Logs Monitor)**

#### الخطوات:
1. أضف دواء جديد عبر "إضافة دواء 💊"
   - اسم: `Aspirin`
   - جرعة: `500mg`
   - مخزون: `20`
   - وقت: `09:00 am`

2. اذهب إلى "أدويتي 📋"

#### ✅ معايير النجاح:
- [ ] ظهور الدواء مع المخزون
- [ ] ظهور قسم "آخر الجرعات" (قد يكون فارغاً في البداية)
- [ ] الصيغة صحيحة:
```
💊 Aspirin | 500mg | 📦 المخزون: 20
  📋 آخر الجرعات:
    📋 لا توجد سجلات جرعات بعد
```

#### 🔍 اختبار متقدم:
3. انتظر وقت التذكير (أو عدّل في الكود لتقليل الفترة)
4. عندما تأتي رسالة التذكير، اضغط "تم التناول ✅"
5. اذهب إلى "أدويتي 📋" مرة أخرى

#### ✅ معايير النجاح المتقدمة:
- [ ] ظهور الجرعة المسجلة في السجل:
```
💊 Aspirin | 500mg | 📦 المخزون: 19
  📋 آخر الجرعات:
    ✅ تم التناول • 2026-06-08 15:45:30
```

#### 🗄️ التحقق من قاعدة البيانات:
```sql
-- تحقق من أن الجرعة تم تسجيلها
SELECT * FROM intake_logs WHERE medicine_id = YOUR_MEDICINE_ID ORDER BY timestamp DESC;

-- يجب أن ترى:
-- medicine_id: رقم الدواء
-- status: 'taken' أو 'skipped'
-- timestamp: الوقت الحالي
```

### **الاختبار 3️⃣: التحكم الكامل بدون ID (No Manual IDs)**

#### 📝 المتطلبات الأساسية:
- [ ] يجب أن تكون Admin (معرّف التليجرام يطابق ADMIN_ID في main.py)
- [ ] يجب أن يكون لديك مرضى بأدوية مسجلة

#### الخطوات:
1. ادخل إلى القائمة الرئيسية
2. اضغط "لوحة الصيدلي 👨‍⚕️"

#### ✅ معايير النجاح:
- [ ] ظهور قائمة بأسماء المرضى (بدون طلب إدخال ID يدوي!)
- [ ] الأسماء تظهر بشكل صحيح مع usernames
- [ ] كل اسم له زر قابل للضغط

#### مثال على الظهور الصحيح:
```
👨‍⚕️ لوحة الصيدلي

📊 عدد المرضى: 3

اختر مريضاً لعرض أدويته وإدارة جرعاته:

[👤 أحمد محمد (@ahmed123)]
[👤 فاطمة علي (@fatima_ali)]
[👤 سارة محمود (@sarah_med)]

[📦 إضافة مخزون سريع]
[📢 إذاعة رسالة جماعية]
```

#### 🔍 اختبار معمّق:
3. اضغط على أي اسم مريض (مثلاً "أحمد محمد")

#### ✅ معايير النجاح المتقدمة:
- [ ] **لم تطلب الرسالة أي إدخال يدوي!**
- [ ] عرض أدوية المريض مباشرة
- [ ] ظهور آخر الجرعات لكل دواء
- [ ] وجود أزرار "إضافة 30 حبة" و "حذف الدواء"

#### مثال على الظهور الصحيح:
```
📋 أدوية المريض:

💊 Aspirin | 500mg | 📦 المخزون: 15
  📋 آخر الجرعات:
    ✅ تم التناول • 2026-06-08 14:30:45
    ✅ تم التناول • 2026-06-07 09:15:20

💊 Vitamins | 1 tablet | 📦 المخزون: 8
  📋 آخر الجرعات:
    ✅ تم التناول • 2026-06-08 08:00:00

[➕ إضافة 30 حبة] [🗑️ حذف الدواء]
[➕ إضافة 30 حبة] [🗑️ حذف الدواء]
```

#### 4️⃣ اختبار الإجراء النهائي:
- اضغط على "إضافة 30 حبة" لأي دواء

#### ✅ معايير النجاح النهائية:
- [ ] **لم تطلب الرسالة أي إدخال يدوي!**
- [ ] ظهور رسالة تأكيد فوراً:
```
✅ تمت إضافة 30 حبة إلى Aspirin.
📦 المخزون الجديد: 45 حبة.
```
- [ ] تحديث المخزون في قاعدة البيانات:

```sql
SELECT stock_quantity FROM medicines WHERE name = 'Aspirin';
-- يجب أن يكون المخزون الجديد = القديم + 30
```

## 🐛 استكشاف الأخطاء

### المشكلة: "لا توجد أدوية مسجلة في هذا الحساب"
```
الحل:
1. تحقق من أن المستخدم أضاف دواء واحد على الأقل
2. تحقق من أن الدواء مربوط بـ patient_id الصحيح
```

### المشكلة: "قائمة المرضى فارغة"
```
الحل:
1. تحقق من أن هناك مرضى بأدوية مسجلة:
   SELECT DISTINCT u.user_id, u.full_name FROM users u 
   JOIN medicines m ON u.user_id = m.patient_id WHERE u.role = 'patient';

2. إذا كانت النتيجة فارغة، أضف دواء كمريض أولاً
```

### المشكلة: "السجل لا يظهر"
```
الحل:
1. تحقق من أن جدول intake_logs موجود:
   SELECT * FROM intake_logs LIMIT 1;

2. اضغط "تم التناول" في التذكير لتسجيل جرعة

3. تحقق من السجل:
   SELECT * FROM intake_logs WHERE medicine_id = YOUR_MED_ID;
```

### المشكلة: "ADMIN_ID غير صحيح"
```
الحل:
1. احصل على معرّفك من التليجرام: اطلب من البوت:
   /start
   (سيظهر رقمك في السجلات)

2. أضفه في main.py:
   ADMIN_ID = 123456789  # ضع رقمك هنا

3. أعد تشغيل البوت
```

## 📊 اختبارات قاعدة البيانات

### 1. التحقق من التسجيل التلقائي:
```sql
SELECT COUNT(*) as total_users FROM users;
```

### 2. التحقق من سجلات الجرعات:
```sql
SELECT COUNT(*) as total_logs FROM intake_logs;
```

### 3. التحقق من أن كل دواء له سجل جرعات:
```sql
SELECT m.id, m.name, COUNT(l.id) as log_count 
FROM medicines m 
LEFT JOIN intake_logs l ON m.id = l.medicine_id 
GROUP BY m.id;
```

### 4. التحقق من المرضى الذين لديهم أدوية:
```sql
SELECT DISTINCT u.user_id, u.full_name, COUNT(m.id) as medicine_count
FROM users u
JOIN medicines m ON u.user_id = m.patient_id
WHERE u.role = 'patient'
GROUP BY u.user_id;
```
